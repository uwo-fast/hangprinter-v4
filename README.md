# FAST's Hangprinter v4

FAST's build of the [Hangprinter](https://hangprinter.org/) v4, the open-source RepRap 3D printer by Torbjørn Ludvigsen. It suspends its print head on cables, allowing for mid-air printing without the constraints of a traditional build volume. The build follows the upstream [v4 documentation](https://hangprinter.org/doc/v4/), with an aluminium-extrusion triangle, a larger power supply, and a Duet 3 Toolboard 1LC for interchangeable extruders. This is not the official Hangprinter v4; the upstream project is at <https://gitlab.com/tobben/hangprinter>.
